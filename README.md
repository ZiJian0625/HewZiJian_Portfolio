## 🌙 About the project

A personal portfolio built to serve as a digital business card and a showcase of my technical journey. It behaves less like a standard résumé and more like a curated exhibition of my skills, projects, and experiences in the tech world.

Under the hood, it is a **fast, static site built with Astro** and served directly from the edge via **Cloudflare Pages**. Styling is handled entirely with **Vanilla CSS** utilizing modern variables and glassmorphism techniques for a sleek, premium feel. **Everything here is built from scratch and tuned by hand.**

<hr/>

## 🧱 Tech stack

| Layer | What |
| :--- | :--- |
| **UI** | Astro components (HTML) |
| **Build** | Astro — `npm run dev` / `npm run build` |
| **Styling** | Vanilla CSS — custom properties, CSS Grid, Glassmorphism, CSS media queries |
| **Interactivity** | Vanilla JavaScript |
| **Graphics** | Inline SVG & CSS animations |
| **Hosting** | Cloudflare Pages — static output, built automatically on push |

<hr/>

## ☁️ Deployment

Hosted on **Cloudflare Pages**. Pushing to the `main` branch on GitHub triggers a build automatically.

**Project settings:**

| Setting | Value |
| :--- | :--- |
| Framework preset | `Astro` |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | *(empty)* |
| Environment | Static SSG |

Check a build locally before pushing with `npm run build && npm run preview`.
